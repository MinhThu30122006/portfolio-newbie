# Phạm Thị Minh Thư - Frontend Portfolio

A modern, responsive portfolio built with React, Vite, and Three.js.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production output is created in `dist/` and can be deployed to Vercel, Netlify, or GitHub Pages.

## Push to GitHub

```bash
git init
git add .
git commit -m "Create React portfolio"
git branch -M main
git remote add origin https://github.com/MinhThu30122006/YOUR-REPOSITORY.git
git push -u origin main
```
